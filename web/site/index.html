Everything a console does. Everything a PC can.

Controller first

PS5 DualSense, PS4 DualShock and Xbox controllers work from the first boot, wired or Bluetooth. No keyboard or mouse needed, ever.

All your games

Steam, Epic, GOG and games you installed yourself appear together on Home, with their artwork, automatically.

Free games

Current giveaways and free-to-play games from the big stores, one press from Home.

Downloads built in

A web browser you drive with the controller and a torrent downloader. Installers and archives become games in your library.

Performance monitor

Live CPU, GPU, memory and temperatures, an in-game overlay, and End task for anything that hangs.

Nine themes, your own wallpaper, navigation sounds and startup music.

Install in three steps

  1. 1

    Download

    Get PC5-OS-Setup.exe with the button above.

  2. 2

    Run Setup

    Double-click it. If Windows says “Windows protected your PC”, choose More info → Run anyway. That message appears for any new app that isn't code-signed yet.

  3. 3

    Pick how it starts

    Console mode starts PC5 instead of the desktop when you sign in. App mode opens it like any other app. Change it any time in Settings → System.

Questions

Does it replace Windows?

No. PC5 OS runs on top of your existing Windows. Your files, apps and games stay exactly where they are.

How do I get back to the normal desktop?

Settings → System → Desktop Mode opens the desktop right away (the PS button brings you back). Switch to Windows signs you in to the regular desktop until you choose to return.

How do I uninstall it?

Windows Settings → Apps → PC5 OS → Uninstall. If console mode was on, the uninstaller switches your PC back to the normal desktop.

Do my PlayStation controllers work in every game?

PC5 adds the games you install yourself to Steam, so Steam Input translates your PlayStation controller for games that only understand Xbox controllers.

Is it free?

Yes. Store games are bought or claimed through their own stores (Steam, Epic, GOG).
